# EducationApps

Biblioteca de aplicaciones educativas **gratuitas para descargar**.

La web no ejecuta ninguna aplicación: cada ficha ofrece un ZIP que se descomprime y se abre en el ordenador, sin conexión y sin instalar nada.

- Web: carpeta `docs/` (publicada con GitHub Pages).
- Catálogo: `docs/datos/catalogo.js`. Es el único archivo que hay que editar para añadir apps.
- Descargas: `docs/descargas/`.
- Cómo añadir o actualizar apps: [COMO_AÑADIR_UNA_APP.md](COMO_AÑADIR_UNA_APP.md).

Estas aplicaciones no sustituyen a los libros oficiales.
